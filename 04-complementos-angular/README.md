# Complementos de Angular

Temas que complementan el curso de Angular y sirven de puente hacia un sistema con mapas:
ciclo de vida de los componentes, formularios reactivos y OpenLayers dentro de un componente.
Fecha de estudio: 28 de octubre de 2026.

## Proyecto

| Carpeta | Qué contiene |
|---|---|
| [`complementos-app`](complementos-app) | Una app con tres páginas: ciclo de vida, formulario reactivo con validaciones y un mapa de OpenLayers |

El proyecto tiene su propio README con el detalle y cómo correrlo.
Se creó con Angular CLI 21, componentes standalone y sin zone.js.
